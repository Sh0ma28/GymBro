# GymBro Web

Журнал тренировок. Данные и импортируемые файлы обрабатываются в браузере. Журнал хранится в локальном хранилище сайта для текущего профиля браузера.

В разделе **Обмен CSV** можно выгрузить записи за период, выбрать CSV и подтвердить его импорт. При импорте совпадающие записи пропускаются, а новые упражнения и группы из файла добавляются в справочник. Назначенная в журнале группа упражнения сохраняется при конфликте.

Поддерживается CSV в UTF-8 с запятой или точкой с запятой в качестве разделителя. Заголовки `Дата`, `Упражнение`, `Подходы`, `Повторения за подход`, `Вес (кг)` соответствуют старым Android-выгрузкам. Веб-версия добавляет необязательный столбец `Группа мышц`. Переносятся данные строк тренировок и связанные с ними упражнения и группы.

Для GitHub Pages задайте в **Settings → Pages** публикацию из корня ветки `main`. Точка входа находится в `index.html`.
